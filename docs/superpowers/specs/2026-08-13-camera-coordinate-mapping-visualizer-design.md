# 相机坐标映射可视化实验台设计

## 目标

创建一个独立的本地交互网页，用空间场景和二维坐标域联动解释当前 `CarPlan_2` 使用的径向几何校正模型。页面服务于教学和算法理解，不修改任何飞控或车模固件。

成功标准：

1. 用户可以拖动车灯像素点，直观看到原始像素误差和校正域误差的差异。
2. 用户可以调节 Roll、Pitch，观察姿态投影中心和误差向量同步变化。
3. 3D 场景、原始像素域、校正坐标域和公式数值使用同一份计算结果。
4. 固定模型参数及投影中心公式与当前固件一致。
5. 桌面和手机视口下内容不重叠，交互控件保持可用。

## 范围

页面包含：

- 相机、地面、视锥、光轴、车灯点和投影光线组成的 3D 场景。
- 原始像素域和校正坐标域两个联动的二维视图。
- 可拖动的车灯像素点。
- Roll、Pitch 滑杆和姿态复位按钮。
- 当前输入、投影中心、映射结果和误差向量数值。
- 固定公式和参数的只读展示。

页面不包含：

- Mode2 的 PD、前馈、姿态限幅或参数调节。
- 飞行日志导入和回放。
- 相机内参、标定板或标准镜头模型求解。
- 像素到厘米的物理距离换算。
- `k4`、`lambda` 或投影中心系数的在线修改。

## 数学模型

投影中心使用当前固件中的近似公式：

```text
p0.x = -0.20 + 1.325 * roll
p0.y = -4.63 + 1.334 * pitch
```

径向几何校正使用：

```text
q = p - (1 / 3) * p0
r = dot(q, q) / 10000
F(p) = q * (1 + 2.4 * r * r)
```

两个视图分别展示：

```text
e_raw = p_lamp - p0
e_corrected = F(p_lamp) - F(p0)
```

`F(p_lamp - p0)` 不作为结果使用，因为非线性映射不满足差值与映射交换。

页面将该公式称为“拟合的径向几何校正映射”，不称为经过相机内参标定确认的严格逆畸变模型。

## 页面布局

### 3D 空间视图

页面上半部分为不加装饰边框的全幅 Three.js 场景：

- 相机位于地面上方，俯视地面。
- 半透明视锥表示可视范围。
- 光轴与地面的交点表示姿态投影中心。
- 地面上的车灯标记对应当前可拖动像素点。
- 两条辅助光线分别连接相机、投影中心和车灯点。
- 调节 Roll、Pitch 时，相机姿态、光轴和投影中心同步变化。

3D 场景用于解释空间关系，不宣称按照真实相机内参还原精确尺度。

### 二维联动视图

页面下半部分并排展示两个 Canvas：

- 原始像素域：规则参考网格、`p_lamp`、`p0` 和 `e_raw`。
- 校正坐标域：将同一组网格采样点经过 `F` 后绘制，显示 `F(p_lamp)`、`F(p0)` 和 `e_corrected`。

车灯点只能在原始像素域拖动。校正域只展示映射结果，避免出现两个相互竞争的输入源。

### 控制与数值

右侧控制区只包含：

- Roll 滑杆。
- Pitch 滑杆。
- 姿态复位按钮。
- 固定参数 `k4=2.4`、`lambda=1/3`。
- 两组误差向量及其模长。

窄屏时控制区移动到视图下方，二维视图改为纵向排列。

## 视觉语言

页面采用深色工程仪器风格：

- 原始像素域使用琥珀色作为主标识。
- 校正坐标域使用青绿色作为主标识。
- 投影中心、车灯点和向量使用稳定且可区分的颜色。
- 网格和辅助线保持低对比度，避免压过主要几何关系。
- 不使用装饰性渐变球、营销式大标题或无关动画。

动画只用于输入变化后的平滑过渡和 3D 场景持续渲染。

## 实现结构

使用一个独立的 Vite 前端目录，核心依赖为 Three.js。代码按职责分为：

- 映射数学模块：投影中心、点映射和误差计算，保持为无状态纯函数。
- 共享状态：车灯点、Roll、Pitch 和派生计算结果。
- 3D 场景：只消费共享状态并更新相机、光线和地面标记。
- 二维视图：只消费共享状态并绘制两个坐标域。
- 控制面板：修改 Roll、Pitch 并显示计算结果。

不引入前端框架或状态管理库，避免为单页演示增加无关复杂度。

## 验证

### 数学验证

- Roll、Pitch 为 0 时，投影中心为 `(-0.20, -4.63)`。
- 任意点 `p` 的页面输出与固件公式逐项一致。
- 当 `p_lamp == p0` 时，两种误差均为零。
- 页面计算 `F(p_lamp) - F(p0)`，而不是 `F(p_lamp - p0)`。

### 交互验证

- 拖动车灯点时，三个视图和数值在同一帧更新。
- 改变 Roll、Pitch 时，投影中心、光轴和两种误差同步更新。
- 复位按钮恢复零姿态，但不移动用户设置的车灯点。
- 拖动范围受到像素视图边界约束。

### 视觉验证

- 使用桌面和手机视口截图检查布局、文字和控件重叠。
- 检查 Three.js 画布存在非背景像素，避免空白场景。
- 检查 3D 相机、视锥、光线和地面目标均在初始视野内。
