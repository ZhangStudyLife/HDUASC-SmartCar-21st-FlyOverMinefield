# Mode 7 姿态二阶参考模型设计

## 目标

在不改变其他飞行模式的前提下，为 Mode 7 的 Roll/Pitch 姿态闭环加入 PX4 风格的二阶临界阻尼参考模型。模型需要提高目标姿态的跟随速度，同时抑制速度环输出目标角度中的高频台阶和估计噪声。

适用机型为 300 g、2004 3000KV 电机、3.5 x 2.5 x 3 桨叶的小型四旋翼。

## 当前控制链

Mode 7 在 50 Hz 运行速度环，输出原始 Roll/Pitch 目标角度。姿态环在 500 Hz 将角度误差乘以角度 Kp，生成目标角速度。角速度环在 1000 Hz 跟踪目标角速度。

当前 Mode 7 已关闭完整目标角度微分前馈和目标角速度微分前馈，只保留速度指令变化率前馈。该行为必须保留，避免微分速度估计反馈和形成二次微分。

## 方案选择

不采用以下方案：

- 只提高角度 Kp：可以减少部分延迟，但会同步放大速度环目标角度的高频抖动。
- 直接微分完整目标角度：会放大速度估计反馈噪声，不适合 Mode 7。
- 恢复角速度环目标微分前馈：会对姿态误差修正再次微分，并激励日志中约 5 Hz 的角速度增益峰值。

采用 Mode 7 专用的标量二阶临界阻尼参考模型。Roll 和 Pitch 分别维护参考角度和参考角速度状态，使用相同的模型参数。

## 控制结构

Mode 7 的 50 Hz 速度环继续输出原始目标角度 `angle_command`。参考模型在 500 Hz 姿态环中运行：

```text
ref_acc = wn^2 * (angle_command - ref_angle)
        - 2 * wn * ref_rate

ref_acc  = clamp(ref_acc, -accel_limit, accel_limit)
ref_rate = clamp(ref_rate + ref_acc * dt, -rate_limit, rate_limit)
ref_angle = ref_angle + ref_rate * dt
```

姿态环生成目标角速度：

```text
rate_feedback = angle_Kp * (ref_angle - actual_angle)
rate_ff       = ref_kff * ref_rate
rate_target   = clamp(rate_feedback + rate_ff, -260, 260)
```

现有角度 PID 的 PT3 50 Hz 输出滤波只作用于误差反馈项。参考角速度前馈不再经过该 PT3，但参考模型本身、速度限幅和加速度限幅共同约束其高频能量。

Mode 7 的角速度环 Kff 继续保持为零。

## 初始参数

参数存放在 `fc_params_t` 和 `fc_params.c` 默认值中，只作为当前固件的源码参数，不增加 AirComm 或车端菜单项目。

```text
mode7_att_ref_wn_radps          = 25.0
mode7_att_ref_kff               = 0.90
mode7_att_ref_rate_limit_dps    = 180.0
mode7_att_ref_accel_limit_dps2  = 6000.0
```

阻尼比固定为 1，不增加可调参数。总目标角速度继续使用现有的正负 260 deg/s 限幅。

第一版保持全局角度参数不变：

```text
Roll angle Kp  = 8.2
Pitch angle Kp = 7.5
Angle PT3 LPF  = 50 Hz
```

这样可以单独验证参考模型，而不会同时改变手动姿态模式的响应。

## 状态管理

参考模型只在 Mode 7 且飞控处于飞行状态时更新。

首次进入 Mode 7、重新进入飞行状态或执行飞控复位时：

- Roll/Pitch 参考角度对齐当前实际角度。
- Roll/Pitch 参考角速度清零。
- 本周期不产生参考速度前馈冲击。

离开 Mode 7 后，其他模式继续使用原有角度 PID 和角度前馈逻辑，不读取 Mode 7 参考模型状态。

## 调试日志

Mode 7 当前日志保持原始目标角度、实际角度、总目标角速度和实际角速度字段。两个当前无效的 Mode 7 内环前馈字段改为记录：

```text
I15 / I16: Roll/Pitch 参考角度
I21 / I22: Roll/Pitch 参考角速度前馈
```

由此可以同时验证原始目标角度、参考角度、实际角度和最终目标角速度。

## 离线验证

至少重放以下日志：

```text
35小飞机速度环输出调试姿态环响应_2.csv
35小飞机速度环输出调试姿态环响应_3.csv
35小飞机速度环输出调试姿态环响应_4.csv
35小飞机速度环输出调试姿态环响应_5.csv
```

离线验证分为两层：

1. 算法重放：以日志原始目标角度和实际角度作为输入，逐采样运行参考模型，比较新旧目标角速度的响应、频谱、限幅和连续性。
2. 闭环预测：使用日志识别的目标角速度到实际角速度模型，比较当前控制器和参考模型控制器的预测姿态响应。闭环预测必须同时报告模型误差，不能当作实飞结果。

离线参数扫描范围：

```text
wn: 20, 22, 25, 28 rad/s
kff: 0.75, 0.90, 1.00
```

如扫描结果显示默认组合不是最优，只调整上述四个 Mode 7 参考模型参数，不同时修改速度环、角度 Kp、角速度环或 IMU 滤波器。

## 验收标准

- 所有指定日志完整重放，无 NaN、无状态发散、无模式切换冲击。
- 1 Hz 等效姿态延迟相对当前控制器至少降低 15 ms。
- 5 至 15 Hz 目标角速度 RMS 不超过当前控制器的 105%。
- 目标角速度 P99 小于 120 deg/s。
- 正负 260 deg/s 总目标角速度限幅触发比例小于 0.1%。
- 闭环预测不得产生持续振荡，且必须保留当前约 5 Hz 内环增益峰值的风险说明。

## 验证边界

日志没有电机输出和混控饱和信息，因此离线结果不能证明电机余量充足。首飞仍需检查 4 至 8 Hz 连续振荡、目标角速度过冲和电机饱和。项目约束禁止由命令行调用 IAR，代码验证只执行静态引用检查、差异检查和离线重放，最终固件编译与实飞由用户完成。

## 非目标

- 不修改 Mode 0、1、2、3、4、5、6、8 的姿态控制行为。
- 不修改 Mode 7 速度环参数。
- 不修改角速度 PID、D 低通、IMU 滤波器或芯片滤波器。
- 不增加新的通用 PID 抽象。
- 不实现完整四元数参考模型；Mode 7 的正负 30 度 Roll/Pitch 范围使用独立标量模型。
