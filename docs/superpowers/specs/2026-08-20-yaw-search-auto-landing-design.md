# Yaw 搜索与自动降落设计

## 目标

修正 `yawmode == 2` 时的信标搜索和 Mode4 自动降落行为：搜索期间提高 yaw 响应速度，根据飞机与车辆的累计相对旋转选择搜索方向，且只有飞机在连续无信标期间实际旋转至少 360 度后才允许自动降落。

车灯不参与信标搜索和自动降落判断。`CarPlan3 result.valid` 也不作为信标可见状态。

## 日志结论

现有搜索目标每 500 ms 增加 45 度。三次自动降落前最后 4.99 秒内，飞机实际净旋转分别约为 214 度、258 度和 134 度，因此搜索目标步数不能代表飞机已经完成 360 度搜索。

日志中当前默认 yaw 角度环 Kp 下，多数 45 度目标需要约 300 至 575 ms 到达。搜索时将 Kp 加倍，并把目标切换周期固定为 750 ms。

## 信标状态

复用 `YawAlign` 当前的三相机信标筛选规则：

- 前、后相机使用现有合格信标筛选，并排除靠近车灯的干扰目标。
- 中相机使用现有中心相机信标筛选。
- 任一相机发现合格信标即视为当前看到信标。

看到信标时立即停止搜索目标切换、恢复默认 yaw 角度环 Kp，并清零连续无信标计时与本轮实际旋转进度。信标再次消失后重新开始一轮搜索。

## 搜索控制

进入 `yawmode == 2` 且连续无信标时：

1. yaw 角度环 Kp 使用 `2.0f * g_fc_params.yaw_angle_kp`。
2. 第一目标基于进入搜索时的飞机实际 yaw，沿本轮方向偏移 45 度。
3. 此后固定每 750 ms 沿同一方向再偏移 45 度。
4. 一轮搜索方向一旦选定，在看到信标或退出搜索前不改变，避免左右往返导致重复扫描同一区域。
5. 看到信标、退出 `yawmode == 2`、`CRSF_STD[4] == 0` 或结束飞行时，恢复默认 yaw 角度环 Kp。

750 ms 是目标切换周期，不是完成 360 度的依据。飞机未追上某个目标时仍可进入下一目标，但自动降落始终受实际旋转角门限保护。

## 线缆防缠绕

在 100 Hz 航向更新中分别展开飞机 yaw 和车辆 yaw，并累计：

```text
cable_twist_deg += aircraft_yaw_delta_deg - car_yaw_delta_deg
```

开始新一轮搜索时：

- `cable_twist_deg > 0` 时选择负方向搜索。
- `cable_twist_deg < 0` 时选择正方向搜索。
- 接近零时优先选择与车辆 yawrate 相同的方向；车辆基本静止时沿上一次搜索的反方向开始。

该方向保持完整一轮。因为无信标时必须覆盖 360 度，车辆静止时线缆至少产生一圈相对旋转无法避免；方向选择的目标是避免在已有扭转上继续累加多圈。

## 实际旋转进度

每次 100 Hz 更新使用飞机相邻两次实际 yaw 的 `[-180, 180]` 包角差。按本轮搜索方向累计有符号净进度：

```text
search_rotation_deg += search_direction * aircraft_yaw_delta_deg
```

反方向运动会减少进度，进度下限为 0 度。这样来回摆动不能伪造完整扫描。看到信标、退出搜索或重新开始一次已确认的信标丢失过程时清零进度。

## 自动降落条件

保留现有 Mode4、飞行状态、`yawmode == 2`、`CRSF_STD[4] == 1` 和时间门限。将目标状态从 `CarPlan3 result.valid` 改为 `YawAlign` 的信标可见状态。

只有以下条件同时满足才请求自动降落：

- 飞机处于 Mode4 飞行状态。
- `yawmode == 2`。
- `CRSF_STD[4] == 1`。
- 已通过现有 5 秒前置等待。
- 连续无信标达到现有 5 秒门限。
- 本轮连续无信标期间飞机实际定向旋转进度至少为 360 度。

`CRSF_STD[4] == 0` 时不进行本算法的搜索和自动降落，yaw 保持现有零目标行为。

## 调试与验证

扩展现有 200 Hz 日志，至少增加以下字段：

- 当前信标可见状态。
- 搜索方向。
- 当前 750 ms 计数。
- 飞机实际搜索旋转进度。
- 线缆累计扭转量。
- 当前 yaw 角度环 Kp。
- 自动降落的 360 度门限状态。

验证标准：

1. 有信标时 yaw Kp 为默认值，搜索目标不再切换。
2. 无信标搜索时 yaw Kp 为默认值的两倍，目标每 750 ms 沿固定方向变化 45 度。
3. 搜索方向优先减小累计线缆扭转。
4. 实际旋转不足 360 度时，无论无信标时间多长都不触发自动降落。
5. 实际旋转达到 360 度且其他现有门限满足后才触发自动降落。
6. 看到信标、关闭 `CRSF_STD[4]` 或退出飞行后恢复默认 Kp，并重置本轮搜索状态。
