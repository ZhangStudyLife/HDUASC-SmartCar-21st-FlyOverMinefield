# Mode 7 飞控响应交互实验室设计

## 目标

制作一个本地交互网页，帮助理解并比较 Mode 7 从遥杆输入到实际姿态响应的完整控制链：

```text
二维遥杆
  -> 目标水平速度
  -> 速度环输出原始目标角度
  -> 二阶临界阻尼姿态参考模型
  -> 姿态角外环输出目标角速度
  -> 角速度内环与机体
  -> 实际角速度、实际姿态和实际水平速度
```

页面的首要目标是解释“跟手”和“抖动”分别来自控制链的哪一层。它不是宣传页，也不把离线模型结果表述为实际飞行保证。

## 适用范围与假设

- 机型是当前 300 g、2004 3000KV 电机、3.5 x 2.5 x 3 桨叶的小型四旋翼。
- 主交互方式是二维虚拟遥杆：左右控制 Roll 方向速度，前后控制 Pitch 方向速度。
- 第一版只支持当前 Mode 7 调试日志的已知字段顺序，不实现任意 CSV 的通用列映射器。
- Roll 和 Pitch 分开辨识与仿真，不假定两轴动力学完全相同。
- 日志没有电机输出、混控饱和、电池电压和完整外部扰动，因此模型只能预测参数变化趋势，不能证明实飞稳定性。
- CSV 使用浏览器本地读取，不上传，也不依赖后端服务。
- 不修改飞控源码、参数默认值或现有日志。

## 选择的方案

采用“日志标定的交互模型”：

1. 使用与固件一致的遥杆映射、速度 PID、姿态参考模型和姿态角外环公式。
2. 从导入日志辨识实际飞机的角速度通道、水平速度通道、延迟、低频增益、共振和噪声。
3. 用辨识结果构成简化机体模型，重放原日志并计算当前参数下的基线。
4. 用户修改参数后，以同一输入和同一机体模型重新运行，显示预测曲线与相对变化。

不采用纯公式演示，因为它与实际飞机差异过大；也不完整移植全部固件，因为日志缺少电机和混控状态，即使增加大量代码也无法得到完整闭环真值。

## 页面结构

页面是一块直接可操作的控制实验台，不设置欢迎页。

### 顶部操作区

- 二维虚拟遥杆默认显示并自动回中。
- 支持鼠标、触摸和键盘操作。
- “保持”按钮允许固定遥杆位置，便于观察稳态误差和积分作用。
- 输入来源只保留两个切换项：`虚拟遥杆` 和 `日志回放`。
- CSV 导入按钮始终可见；导入成功后显示文件名、采样率、有效时长和有效 Mode 7 样本比例。

### 参数区

参数按照实际控制层分组，不按数据类型堆放：

1. 遥杆映射：最大速度、死区、Expo。
2. 速度环：X/Y 的 Kp、Ki、Kff、前馈一阶滤波和目标角度限幅。
3. 姿态参考模型：wn、前馈比例、反馈比例、前馈低通、角速度限幅、角加速度限幅。
4. 姿态角外环：Roll/Pitch Kp 和最终目标角速度限幅。
5. 角速度内环：Roll/Pitch 的 Kp、Ki、Kd 和 D 项低通；Kff 显示为 Mode 7 固定关闭，不提供一个与当前固件不一致的可调滑杆。

每个参数只显示一句直接解释，例如：

- `wn`：增大后参考角更快，但会把更多高频目标交给内环。
- 速度 Kp：增大后速度误差更快转成倾角，但更容易形成目标角抖动。
- 姿态 Kp：增大后姿态误差更快转成目标角速度，但会提高内环负担。
- 角速度 Kd：增加阻尼并抑制快速过冲，过大时会放大陀螺仪噪声。

不增加高级模式、参数搜索器或自动写代码功能。

### 信号链提示

参数区旁显示紧凑的控制链。当前正在调整的参数组高亮，并在其下游信号上显示影响方向，使用户能区分：

- 遥杆 Expo 造成的中心区迟钝；
- 速度环造成的目标角度迟缓或抖动；
- 参考模型造成的平滑与延迟；
- 姿态外环造成的目标角速度大小；
- 角速度环和机体造成的共振、过冲与噪声。

### 时域曲线

主图按同一时间轴显示，可按控制层单独开关：

- 目标速度与实际速度；
- 速度环原始目标角度；
- 参考模型目标角度；
- 实际 Roll/Pitch；
- 目标角速度与实际角速度；
- 速度环 P/I/FF、姿态角反馈和参考角速度 FF 的贡献。

实时遥杆模式保留最近 8 秒曲线。日志回放模式显示原始实飞曲线、当前模型回放曲线和修改参数后的预测曲线。

### 频域曲线与指标

频域区域显示测量值、当前模型和修改后模型的闭环增益，重点标出 3 至 8 Hz 区间。指标区同时显示 Roll 和 Pitch 的：

- 端到端等效延迟；
- 10% 至 90% 上升时间；
- 超调量；
- 0.5 至 1 Hz 跟踪增益；
- 3 至 8 Hz 最大增益；
- 5 至 15 Hz 高频能量；
- 参考角速度、角加速度和最终角速度限幅触发比例。

“跟手程度”和“抖动风险”只作为同一日志、同一辨识模型下的相对评分，并明确显示“不可跨飞机比较”。

## CSV 输入合同

支持语义列名，也支持当前上位机生成的 `I0` 至 `I24` 表头。当前固定格式共有 25 列：`I0` 是毫秒时间戳，`I1` 至 `I24` 对应 `wifi_justfloat()` 的 24 个通道：

```text
vel_x_target, -Pos_Est_vel_x, vel_x_P, vel_x_I, vel_x_FF, roll_angle_target,
vel_y_target, -Pos_Est_vel_y, vel_y_P, vel_y_I, vel_y_FF, pitch_angle_target,
roll_actual_angle, pitch_actual_angle,
roll_reference_angle, pitch_reference_angle,
roll_target_rate, pitch_target_rate,
roll_actual_rate, pitch_actual_rate,
roll_reference_rate_ff, pitch_reference_rate_ff,
mode, state
```

这 24 个通道与当前飞控发送顺序逐项对应；不带表头时也按相同位置解释。解析器只做以下必要处理：

- 自动识别逗号分隔和是否存在表头；
- 删除无法转换为数值的空行；
- 根据时间戳回退分割多段记录；
- 只用 `mode == 7` 且飞控状态有效的连续区间进行辨识；
- 检查采样率、字段数量、时间单调性和关键字段是否有变化。

字段数量或顺序不匹配时停止分析，并列出期望字段；不根据波形形状猜测列含义。

## 日志标定方法

每个连续飞行区间独立处理，再按有效时长加权汇总：

1. 由时间戳中位间隔估计采样率，并重采样到均匀时间轴。
2. 用带限互相关估计以下通道的延迟：目标速度到实际速度、目标角度到实际角度、目标角速度到实际角速度。
3. 用交叉功率谱估计闭环频率响应和相干度；低相干频点不参与参数拟合。
4. 使用当前已知的角速度 PID，从目标角速度到实际角速度的闭环响应反推一个最小的带纯延迟机体角速度对象；拟合目标是让当前 PID 下的模型闭环重现日志中的自然频率、阻尼、低频增益和共振峰。
5. 从姿态角和水平速度关系拟合水平加速度增益、速度阻尼和低频扰动偏置。
6. 用实飞输出减去模型输出的残差估计噪声能量和 3 至 8 Hz 共振峰。

标定完成后先用当前参数重放原日志。只有回放误差达到验收标准，才启用参数变化预测；否则仍可显示原始日志和频谱，但禁用预测评分并说明原因。

## 仿真模型

网页按照固件实际周期运行控制器：速度环 50 Hz、姿态角环 500 Hz、角速度环 1000 Hz；绘图刷新频率与控制计算分开。最小模型为：

1. 遥杆映射生成 X/Y 目标速度。
2. 速度 PI 与速度变化率前馈生成原始目标 Roll/Pitch。
3. 二阶临界阻尼参考模型生成参考角度和参考角速度。
4. 姿态角反馈与参考角速度前馈生成目标角速度。
5. 角速度 PID 驱动辨识出的机体角速度对象，生成实际角速度并积分得到实际姿态。
6. 实际姿态通过重力倾斜分量和辨识出的速度阻尼生成实际水平速度。

Roll/Pitch 的符号按当前日志合同处理，展示层使用用户熟悉的 Roll/Pitch 名称。外部线缆持续拉力只作为日志中辨识出的低频偏置显示，不增加一个无法从现有日志可靠估计的复杂线缆模型。

## 内置预设

只保留四个用于对比的预设：

- 当前 Mode 7：使用当前固件参数。
- 基础串级 PID：关闭二阶参考状态与参考角速度前馈，用于理解参考模型的作用。
- 更激进：提高参考模型带宽和姿态反馈，展示延迟下降与共振风险。
- 更高阻尼：降低参考带宽或提高内环阻尼，展示高频下降与响应变慢。

除“当前 Mode 7”外，其余预设标为教学示例，不作为直接试飞推荐值。

## 视觉与交互约束

- 使用深色示波器风格，但保证文字和曲线具有足够对比度。
- Roll、Pitch、实飞、当前模型和预测模型采用固定颜色，不因图表切换而改变。
- 桌面端以参数区和图表并排显示；窄屏改为单列，最低支持 320 px 宽度。
- 所有颜色、间距和字号使用主题变量，避免散落的硬编码样式。
- 数值输入、滑杆和虚拟遥杆均支持键盘；不能只依赖颜色表达风险。
- 动画只用于实时曲线，不添加装饰性背景或与分析无关的效果。

## 技术实现边界

- 实现为本地单页工具，使用浏览器 `FileReader` 读取 CSV。
- 不建立服务器、不上传日志、不接数据库。
- 绘图使用本地代码或工作区已有依赖，不依赖运行时网络资源。
- 控制器计算、辨识计算和绘图分开组织，但不建立通用插件系统或与本任务无关的抽象层。
- 第一版不导出固件参数文件，不自动修改 `fc_params.c`。

## 验收标准

### 日志与模型

- 能导入 `35小飞机速度环输出调试姿态环响应_建模.csv`，并正确识别时间、Mode 7 有效区间和 Roll/Pitch 字段。
- 当前参考模型重放的参考角 MAE：Roll 小于 0.05 deg，Pitch 小于 0.05 deg。
- 最新日志约 0.98 Hz 的姿态响应能够显示实测基线：Roll 延迟约 65 ms、Pitch 延迟约 62 ms，允许因分段和窗函数产生 10 ms 以内差异。
- 频域图能显示约 3 至 8 Hz 的姿态/角速度增益峰值，并显示相干度不足的频点不可作为结论。
- 参数恢复为当前 Mode 7 预设时，预测曲线恢复到标定基线，数值计算无 NaN、无状态发散。

### 交互

- 拖动二维遥杆后，目标速度、原始目标角度、参考角度、目标角速度和实际姿态按控制链顺序变化。
- 当前遥杆映射在 10%、20%、30%、50% 和 100% 输入时分别接近 8.7、21.5、35.1、67.2 和 200 cm/s。
- 修改任一参数时，只重算其下游信号和全部派生指标，不改变导入的实飞曲线。
- 能在“虚拟遥杆”和“日志回放”之间切换，且切换不会丢失当前参数。
- CSV 解析失败时明确显示缺少或不匹配的字段，不生成预测结果。

### 交付边界

- 页面在本地无需网络即可运行。
- 桌面和 320 px 窄屏均可操作。
- 不修改 Air、Car 或 Car_F 子仓库。
- 不覆盖当前工作区已有的设计文档和其他未提交修改。
