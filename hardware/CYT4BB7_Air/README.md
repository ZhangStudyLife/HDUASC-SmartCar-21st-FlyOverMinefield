# 飞控板（Flight Controller）

> 车机协同系留四旋翼 · 飞控板 · 第 21 届全国大学生智能汽车竞赛「飞跃雷区」组

## 板卡定位

飞控板是整机的**传感器与姿态控制中枢**：

- 采集机上大部分传感器数据（4 路 ToF 定高、ICM42688P 陀螺仪、总钻风摄像头图像）；
- 实现四旋翼的基础功能——姿态平衡、定高、读取摄像头数据；
- 通过串口系留线缆与地面麦轮车交换数据，实现「飞机识别信标、地面车追灯轧灯」的车机协同。

## 电源树

```
VBAT (4S ≈14.8V)
  │  SMAJ18CA (TVS) + FB3 磁珠 + 22μF/100nF 去耦
  ▼
TPS54202DDCR (U12) ──► VCC5V (5V, L3=10μH, 实测约 5.2V)
  │
  ├─► 双路同步降压 DCDC (U3, 逐飞 CYT4 供电方案)
  │     ├─► VCC3V3CORD = 3.3V  (L1=2.2μH) ──► CYT4 VDDD / VDDA / VDDIO / VREFH
  │     └─► VCC1V15   = 1.15V (L2=2.2μH) ──► CYT4 VCCD 内核
  │
  ├─► RT9013-3.3GB (LDO1) ──► VCC3V3CIMU (IMU 专用 3.3V)
  ├─► RT9013-3.3GB (LDO2) ──► VCCCAM    (摄像头专用 3.3V)
  └─► 5V 直供：TOF×4 / 蜂鸣器 / 遥控 / 扩展口 / WiFi / IPS
```

| 电源轨 | 芯片 | 输入 → 输出 | 用途 |
|--------|------|-------------|------|
| VCC5V | TPS54202DDCR（U12） | VBAT → 5V | 主电源（L3=10μH） |
| VCC3V3CORD | 双路 DCDC（U3，第 1 路） | 5V → 3.3V | 主控数字/模拟/IO 供电（L1=2.2μH） |
| VCC1V15 | 双路 DCDC（U3，第 2 路） | 3.3V → 1.15V | 主控内核 VCCD（L2=2.2μH） |
| VCC3V3CIMU | RT9013-3.3GB | 5V → 3.3V | IMU 专用（隔离） |
| VCCCAM | RT9013-3.3GB | 5V → 3.3V | 摄像头专用（隔离） |
| 输入保护 | SMAJ18CA（U1） | VBAT ↔ GND | TVS 防浪涌 |

**主控电源域规格**：VCCD=1.1~1.15V（内核）/ VDDD=2.7~5.5V / VDDA / VDDIO_1 / VDDIO_2 / VREFH。

设计要点：
- 外设供电用独立 LDO 隔离（IMU、摄像头各一路），避免单外设损坏连带整个电源轨；
- 模拟域用 0Ω 磁珠隔离：VCC3V3CORD → FB1 → VDDA，GNDCORD → FB2 → VSSA，VDDA → R2=0Ω → VREFH；
- 内核电压上电监测：U4 运放比较 VCC1V15 与 VCC3V3CORD，输出 CRPG 到 MCU P22.1。

## 器件选型

| 器件 | 型号 | 选型理由 |
|------|------|----------|
| 主控 | CYT4BB7CEX | 汽车级可靠性、逐飞生态成熟（选型理由由软件侧补充） |
| 5V 降压 | TPS54202DDCR | 4S 直降 5V、SOT-23-6、成本低 |
| 主控供电 | 双路同步降压 DCDC（逐飞方案） | 5V → 3.3V + 1.15V 双输出，覆盖 VDDD/VCCD |
| 3.3V LDO | RT9013-3.3GB ×2 | 低噪声、SOT-23-5、外围简单 |
| 陀螺仪 | ICM42688P | 自制 FPC 陀螺仪（见 `FPC-Gyro`） |

> 主控供电采用逐飞 CYT4BB7 核心板方案（双路 DCDC 出 3.3V + 1.15V）。参考：

## 上电与测试

- 无专门测试点，多数调试为「怼引脚」测试；
- 内核电源上电由 U4 比较器监测（CRPG），可用作上电顺序参考；
- 建议流程：先断主控量 5V / 3.3V / 1.15V 各轨 → 焊主控 → 量 VCCD/VDDD → 烧录 → 回读陀螺仪/ToF。
