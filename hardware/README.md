# 硬件设计（Hardware）

> 车机协同系留四旋翼 · 全部自研硬件 · 第 21 届全国大学生智能汽车竞赛「飞跃雷区」组

## 概述

本目录包含「飞跃雷区」系统的**全部自研硬件设计**，共 7 块板卡，由队伍中唯一的硬件负责人独立设计完成。

系统由一架四旋翼飞行器与一辆麦克纳姆轮（麦轮）地面车组成，两者通过**系留线缆（供电 + 信号）**相连：飞行器识别信标与车灯，将感知结果和自身姿态下发给地面车，地面车据此追灯、轧灯。

- 3 × MT9V034 总钻风全局快门摄像头

- ICM42688 陀螺仪（自制 FPC 板）

  ├─► 车控板：[待补充]
  ├─► 图像板：[待补充]
